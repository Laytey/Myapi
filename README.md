
# Myapi — Backend-сервис на Go

Учебный проект, демонстрирующий полный цикл разработки backend-сервиса на Go: от базового REST API до production-ready приложения с аутентификацией, HTTPS, миграциями, тестами и CI/CD.

Проект развивался итеративно в рамках курса, поэтому включает в себя множество технологий и паттернов, применяемых в реальной разработке.

## Функциональность

- **REST API** для управления пользователями и задачами (CRUD).
- **JWT-аутентификация**: защита эндпоинтов с помощью Bearer-токенов.
- **PostgreSQL**: хранение данных с использованием драйвера `pgx`.
- **Миграции**: управление схемой БД через `golang-migrate`.
- **Retry-механизм**: устойчивое подключение к PostgreSQL с повторными попытками.
- **HTTPS**: поддержка защищённого соединения (TLS).
- **Gzip-сжатие**: middleware для сжатия ответов.
- **Unit-тесты**: покрытие бизнес-логики (сервисов) и хендлеров.
- **Моки**: использование `mockery` для изоляции зависимостей в тестах.
- **Бенчмарки**: измерение производительности ключевых операций.
- **CI/CD**: автоматическая проверка кода через GitHub Actions (`golangci-lint`).
- **Docker**: контейнеризация приложения и базы данных, запуск одной командой.

## Быстрый старт

### Требования:
- Docker Desktop (или Docker + Docker Compose)

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/Laytey/Myapi.git
cd Myapi
```

### Шаг 2. Запуск
```bash
docker compose up --build -d
```

После запуска:

- API доступно по адресу http://localhost:8080
- PostgreSQL доступен на порту 5432

### Шаг 3. Проверка
```bash
curl http://localhost:8080/health
```

## Тестирование
Проект покрыт тестами:

- Unit-тесты (сервисы, хендлеры) — go test ./...
- Бенчмарки — go test -bench=. ./...
- Моки для репозиториев — mockery

Для запуска всех тестов:
```bash
go test ./...
```

## Аутентификация (JWT)
Эндпоинты, требующие аутентификации, защищены middleware. Для доступа необходимо:

1. Получить токен через POST /login.

2. Передавать его в заголовке Authorization: Bearer <token>.

## Docker

docker-compose.yml поднимает:
- PostgreSQL с healthcheck.
- migrate — автоматически применяет миграции при старте.
- myapi — само приложение.

Это позволяет развернуть проект одной командой без ручной настройки.

## CI/CD
В проекте настроен GitHub Actions workflow (.github/workflows/lint.yml), который при каждом пуше запускает golangci-lint для проверки качества кода.
